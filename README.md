# Sales Analytics Dashboard - Power BI

## Project Overview
This is an interactive Sales Analytics Dashboard built using Power BI.  
The project analyzes sales performance, customer behavior, and product insights using a large dataset.

## Key Features
- Data cleaning and transformation using Power Query
- Data modeling with Star Schema
- Relationships between Fact and Dimension tables
- DAX measures for business insights
- Multi-page interactive dashboard

## Dashboard Pages
1. Sales Analysis
2. Customer Analysis
3. Product Analysis

## Tools Used
- Power BI Desktop
- Power Query
- DAX
- Data Modeling
