# Sales Analytics Dashboard - Power BI

## Project Overview
This project is an interactive Sales Analytics Dashboard built using Power BI.  
I worked with a sales dataset, cleaned and transformed the data, and designed a structured data model to analyze sales, customers, and product performance.

## What I Did
- Cleaned and transformed data using Power Query
- Designed a star-schema style data model
- Created Fact and Dimension tables:
  - Fact
  - DimCustomer
  - DimProduct
  - DimDate
  - DimShipment
- Defined relationships between tables
- Created DAX measures for business insights
- Built a multi-page interactive dashboard

## Dashboard Pages
1. Sales Analysis
2. Customer Analysis
3. Product Analysis

## Key Measures
- Total Sales
- Total Customers
- Average Order Value
- Avg Sales Per Customer
- Orders Per Customer

## Tools Used
- Power BI Desktop
- Power Query
- DAX
- Data Modeling
